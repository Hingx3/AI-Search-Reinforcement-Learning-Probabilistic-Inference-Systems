# Intelligent Agents and Machine Learning Systems

This repository contains a collection of Artificial Intelligence and Machine Learning projects developed using the UC Berkeley Pacman AI framework.

The project series covers fundamental AI techniques including:

* Search Algorithms (DFS, BFS, UCS, A*)
* Adversarial Search (Minimax, Alpha-Beta Pruning, Expectimax)
* Reinforcement Learning (Value Iteration, Q-Learning, Approximate Q-Learning)
* Probabilistic Inference (Bayesian Networks, Hidden Markov Models, Particle Filters)
* Machine Learning and Neural Networks (Perceptrons, Feedforward Networks, Recurrent Neural Networks)

These projects demonstrate the implementation of core AI concepts used in modern autonomous systems, decision-making agents, probabilistic reasoning systems, and machine learning applications.

## Project Highlights

### Search and Path Planning

Implemented classical search algorithms including:

* Depth-First Search (DFS)
* Breadth-First Search (BFS)
* Uniform Cost Search (UCS)
* A* Search

### Multi-Agent Decision Making

Developed intelligent agents capable of adversarial reasoning using:

* Minimax Search
* Alpha-Beta Pruning
* Expectimax

### Reinforcement Learning

Implemented:

* Value Iteration
* Q-Learning
* Approximate Q-Learning

### Probabilistic Inference

Built probabilistic reasoning systems using:

* Bayesian Networks
* Variable Elimination
* Hidden Markov Models
* Particle Filters

### Neural Networks

Developed machine learning models including:

* Perceptron Classifier
* Feedforward Neural Networks
* Recurrent Neural Networks (RNNs)

Applications included:

* Function Approximation
* Handwritten Digit Recognition (MNIST)
* Language Identification
